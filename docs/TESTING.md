## 隔离与测试限制

使用独立的空白世界和上一版独立测试存档，不使用正式服世界、玩家存档、岛屿数据库或代理连接。容器不联网、不发布游戏端口，测试只能写独立副本。

ServerPlayer、导航 View 和消息接收器为合成对象；实际服务器类及 Mixin 会执行，但没有真实客户端。消息接收器只记录发送分支，未验证实际 NeoForge 客户端握手。

这些结果不代表真实船体已经完成飞行，也不代表图形客户端已完成验收。未在纯 NeoForge 或其他 Interstellaris/Sable 版本完成相同验证。

先运行 `build.py` 和 `build_tests.py`，准备依赖安装目录，然后使用全新的测试目录：

```bash
python3 test_navigation_server.py 1 --server-root /path/to/server --test-dir /path/to/new-isolated-test
# 确认第一阶段结果并且容器正常退出后，再运行第二阶段：
python3 test_navigation_server.py 2 --server-root /path/to/server --test-dir /path/to/new-isolated-test
```

此脚本针对固定 Youer 版本，复制代码 JAR、生成独立测试配置和世界；不复制生产插件或数据库。默认容器名称为 `iss-navigation-test-1/2`，已有同名容器时需要自行选择新的 `--container-prefix`。正常退出码本身不能代替查看探针中的 PASS / TEST_FAILURE 结果。

**探针会主动关闭其所在的测试服务端，禁止安装到正式服。**

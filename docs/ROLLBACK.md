# 回滚

本候选不自动安装、热加载或重启服务器。

后续如需从 2.1.1 回退：

1. 正常保存并关闭服务端，退出客户端，保留新版本日志、配置和访问记录。
2. 客户端和服务端同时移走新 JAR，恢复原版本，保证每端只保留一个本模组版本。
3. 2.1.1 与 2.1.0 使用相同存档格式、注册标识和网络协议；无需重建核心、恢复世界或重置访问记录。
4. 回退 2.0.0 后空间站导航不可用，但核心环境功能仍保留。信息中心如保存了空间站目标，通过原有界面重新选普通天体即可。
5. 正常启动后检查核心、空气、重力、温度、地图和原生导航。

不要用旧的世界或数据库覆盖回滚后的新数据。访问记录可保留；2.0.0 不使用新增的访问记录。

更早的 1.x 没有核心方块，不能直接套用本流程；必须单独评估方块和配置格式兼容性。
